关键约束

🔒 权限隔离

collector 和 analyzer 没有 Write 权限，只能通过返回 JSON 传递数据。organizer 是唯一能写入 knowledge/articles/ 的角色（红线 #1）。

🔗 Agent ↔ Skill 分工

Agent 定义「做什么、输出什么」（角色职责 + 输出契约）。Skill 定义「怎么做」（逐步 SOP）。一个 Agent 可调用多个 Skill，一个 Skill 可被多个 Agent 复用。

📋 Skill 可独立演进

新增采集源（如 hacker-news）只需添加一个 Skill 文件，collector 的角色定义和输出契约不需要修改。tech-summary 可消费任意来源的采集文件。

📊 Knowledge 是最终真相

raw/ 保存原始采集结果（供审计和重跑）。articles/ 保存经分析、去重、Schema 校验后的结构化知识条目。相同 URL 不覆盖，保留历史版本（红线 #6）。
